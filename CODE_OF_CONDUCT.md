# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

In short: be respectful, assume good faith, and keep discussion focused on the
work. Harassment of any kind is not tolerated. Maintainers may remove, edit, or
reject contributions and comments that violate this code.

Report issues to the repository maintainer via a private channel or a
confidential issue.
